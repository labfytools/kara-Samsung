# Kara, lecture Strawberry

Lance le morceau original dans Strawberry et ouvre Kara sur la télévision Samsung. L’application présente la pochette et les paroles du fichier LRC. Le lecteur conserve les pauses et déplacements. Le décalage manuel se règle depuis **Minutage** dans Parole.

Le microphone est relié à l’enceinte EDENWOOD. Le volume du microphone se règle sur l’enceinte, et le volume musical dans Strawberry.

Consulte [l’installation Samsung](../tizen/app/README.md), les [fonctions de bibliothèque](parole-v3.md) et les [diagnostics](../blackbox/README.md).
